# 2026-09-29 개인 업무일지 초안

## 오늘 목표

활성 교육용 OpenAI API 프로젝트로 고정 입력을 실제 생성하고, 형식 안정성·응답 시간·사실 보존을 점검해 보고서 근거를 만든다.

## 완료한 작업

- `gpt-5-mini` Responses API로 정상 상품 입력 4건을 실제 실행했다.
- 오류 입력 4건이 모델 호출 전에 모두 거부되는 것을 확인했다.
- 모델이 해시태그에 `#`과 구두점을 붙여 엄격 검증에서 거부되던 문제를 발견했다.
- 해시태그의 문자·숫자·밑줄만 남기는 결정적 정규화를 추가하고, 본문과 상품 사실은 수정하지 않도록 했다.
- 가격의 `29,000원` 같은 표시를 입력의 `29000`과 다른 숫자로 판단하던 자동 검사의 오탐을 수정했다.
- 결과 원문, 응답 시간, 자동 검사와 Codex 보조 검토를 JSON·Markdown으로 저장했다.
- 390×844 모바일 화면에서 이용자 피팅룸과 판매자 광고 스튜디오를 점검했다.
- 피팅룸에 손가락 조작 안내와 옷걸이 이동 버튼을 추가하고 확대·시점·찜·입어보기 등 주요 버튼의 터치 영역을 키웠다.

## 모바일 사용성 점검

- 브라우저 화면을 390×844로 맞춰 가상 상점 입장, 아바타 확인, 옷걸이 탐색과 광고 입력 화면을 확인했다.
- 가로 화면 넘침은 발견되지 않았다.
- 기존 화면에서는 확대·축소, 시점 변경, 찜하기와 입어보기 버튼 일부가 26~38px로 작았다.
- 주요 조작 버튼을 40~48px로 키우고, 아바타 아래에서 옷걸이로 바로 이동하는 버튼을 추가했다.
- 이 결과는 브라우저의 모바일 화면 점검이며 실제 휴대전화의 터치 감각과 성능은 별도로 확인해야 한다.

## 오후 추가 작업 (Claude Code 보조)

- 판매자 등록 흐름을 샘플 상품으로 끝까지 눌러 보며 결함 3건을 찾아 고쳤다: 광고 스튜디오에서 하의·모자를 불러오면 카테고리가 비어 생성이 막힘, 카테고리를 바꾸면 화면에 없는 실측 칸의 값이 저장을 막음, 기본 상점명이 시연 상점과 같아 시연 상품이 내 매장에 섞임.
- 광고 스튜디오에 등록 상품 선택기를 넣고, 사진을 고르기 전에는 "참고 이미지"로 표시하도록 했다.
- 피팅룸에서 상품 카드와 아바타의 옷을 클릭해 입고 벗을 수 있게 했다.
- 마네킹을 높이별로 실측해 옷의 위치·폭을 맞췄고, 마네킹이 옷 밖으로 나오는 비율을 재는 자동 검사를 추가했다.
- 실제 상품 사진 두 장(카펜터 하프팬츠, 오픈카라 셔츠)으로 시험했다. 사진에서 대표색을 찾아 3D 색으로 쓰고, "셔츠"·"카펜터" 문구가 있으면 해당 세부 디자인을 그린다. 사진에서 3D 형태를 자동으로 만들지는 않으며 두 상품의 실측값은 사진 비율로 추정한 시험용이다.
- 평면 촬영한 상의 사진(오픈카라 셔츠)에서 윤곽을 따 앞면 무늬를 3D 상의에 입히는 최소 버전을 만들었다. 판매자가 체크했을 때만 적용하고, 텍스처는 그 탭의 sessionStorage에만 두며 서버·localStorage에는 저장하지 않는다. 실제 셔츠 사진으로 카라·단추·가슴 주머니·원단 결이 3D에 나오는 것을 화면에서 확인했다. 하의와 착용컷 사진은 아직 지원하지 않는다.
- 자동 검사 96개, 타입 검사, 프로덕션 빌드를 iCloud 밖의 새 폴더에서 통과했다(이후 텍스처 작업으로 검사는 102개가 됐고 임시 복사본에서 통과했다).
- 이 프로젝트 폴더가 iCloud 동기화 대상이라 로컬 git 히스토리 팩 파일이 비워져 있어(다운로드 안 됨), `git add`가 멈춘다. 커밋은 `core.autocrlf=false` 옵션으로 우회했다. 저녁에 파일이 다시 비워져 클론이 실패해, 검증해 둔 `git bundle` 백업에서 iCloud 밖(`~/Projects/fitroom`)으로 복제한 뒤 그 복제본에서 설치·검사 102개·타입·빌드·린트 오류 0을 확인하고 비공개 GitHub 저장소(`cjkj1234/fitroom`)에 게시했다.
- 임시 가상환경(저장소 밖)에 `python-docx`·`reportlab`을 설치해 보고서 PDF·DOCX를 다시 만들었다(9쪽, 검사 102개·GitHub 게시 사실 반영). 표지 서비스 주소 등 다른 내용은 그대로다.
