# 2026-09-29 개인 업무일지 초안

## 오늘 목표

활성 교육용 OpenAI API 프로젝트로 고정 입력을 실제 생성하고, 형식 안정성·응답 시간·사실 보존을 점검해 보고서 근거를 만든다.

## 완료한 작업

- `gpt-5-mini` Responses API로 정상 상품 입력 4건을 실제 실행했다.
- 오류 입력 4건이 모델 호출 전에 모두 거부되는 것을 확인했다.
- 모델이 해시태그에 `#`과 구두점을 붙여 엄격 검증에서 거부되던 문제를 발견했다.
- 해시태그의 문자·숫자·밑줄만 남기는 결정적 정규화를 추가하고, 본문과 상품 사실은 수정하지 않도록 했다.
- 가격의 `29,000원` 같은 표시를 입력의 `29000`과 다른 숫자로 판단하던 자동 검사의 오탐을 수정했다.
- 결과 원문, 응답 시간, 자동 검사와 Codex 보조 검토를 JSON·Markdown으로 저장했다.
- 390×844 모바일 화면에서 이용자 피팅룸과 판매자 광고 스튜디오를 점검했다.
- 피팅룸에 손가락 조작 안내와 옷걸이 이동 버튼을 추가하고 확대·시점·찜·입어보기 등 주요 버튼의 터치 영역을 키웠다.

## 평가 결과

| 항목 | 결과 |
| --- | --- |
| 정상 입력 | 4/4건 구조 검사 통과 |
| 오류 입력 | 4/4건 요청 전 거부 |
| 평균 응답 시간 | 19.1초 |
| 응답 시간 범위 | 14.8–22.5초 |
| 미입력 성능·숫자 후보 | 0건 |
| Codex 보조 검토 | 사실 5.00 · 톤 3.75 · 활용 4.00/5 |

할인 홍보 결과는 가격과 할인율을 정확히 반영했지만 요청한 활기찬 말투는 비교적 차분했다. 보조 검토는 사람 평가를 대신하지 않으므로 사용자가 원문을 확인해 최종 점수를 승인하거나 수정해야 한다.

## 모바일 사용성 점검

- 브라우저 화면을 390×844로 맞춰 가상 상점 입장, 아바타 확인, 옷걸이 탐색과 광고 입력 화면을 확인했다.
- 가로 화면 넘침은 발견되지 않았다.
- 기존 화면에서는 확대·축소, 시점 변경, 찜하기와 입어보기 버튼 일부가 26~38px로 작았다.
- 주요 조작 버튼을 40~48px로 키우고, 아바타 아래에서 옷걸이로 바로 이동하는 버튼을 추가했다.
- 이 결과는 브라우저의 모바일 화면 점검이며 실제 휴대전화의 터치 감각과 성능은 별도로 확인해야 한다.
